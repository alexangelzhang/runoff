## Title

Welcome to runoff — start here

## Body

Hi, I'm the author of runoff.

**runoff** is a multi-step code-change pipeline for coding agents — declare a DAG, race two providers on the same task, pick the winner before any code lands in your repo.

```
npx runoff init --work-dir /path/to/your/repo
```
